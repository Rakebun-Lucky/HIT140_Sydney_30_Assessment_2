# FIFA World Cup 2026 — Data Analysis (Group Project)

Group project analysing FIFA World Cup 2026 data using Python. Four team members, four distinct analytic tasks — each combining data wrangling, sampling, descriptive statistics, a confidence interval, and a t-test.

**Data source:** [FBref.com](https://fbref.com/en/)

## Repo Structure

Each member has their own folder containing their Python file (or notebook), dataset, and output chart.

- `member1_name/`
  - `task_name.py` (or `.ipynb`)
  - `dataset.csv`
  - `chart.png`
- `member2_name/`
  - `task_name.py`
